# Shepherdess website instructions

- This repository is PUBLIC marketing-site source. Do not add private cooperative
  research, member data, simulation results, credentials or unpublished claims.
- `index.html` is the maintained landing page; `stylesheets/landing.css` and local
  images supply its presentation. Read README.md before editing.
- GitHub Pages publishes the root of `main` to shepherdess.io. Distinguish branch
  previews from public deployment and follow the owner's requested scope.
- Check main, open PRs/issues and concurrent activity before editing or merging.
  Use a focused branch/PR and keep its issue current. Cooperative work is tracked
  on the existing internal Project 1; access to that board is separate from this
  public repository's visibility.
- Preserve existing copy, contact destinations and imagery for visual-only work.
  Do not imply field validation or a working AI service from a design change.
- Check narrow/desktop layouts, internal links, accessible names, contrast,
  keyboard navigation and reduced-motion behavior for landing-page changes.
  The `_qa` directory holds public-safe review evidence; local environment paths,
  private recovery exports and credentials do not belong in it.
- Leave historical field/demo files alone unless explicitly in scope. No need to
  run their dependencies to develop the static landing page.
